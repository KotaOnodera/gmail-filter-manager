## 実環境での確認

所有者が承認したアカウントで、インストーラーの配置、標準Cloudプロジェクトとの接続とAPI有効化、指定フォルダへのスプレッドシート作成、4シートの準備、紐付けGASの作成・配置・読み返し、インストーラー経由のコード更新を確認しました。ブラウザで4シートとGmail管理メニューも確認しています。

初回の実フィルター取り込みでは、数値指定で全列幅を選んだ範囲への行メタデータ追加が拒否されました。[Google公式の例](https://developers.google.com/apps-script/reference/spreadsheet/range#adddevelopermetadatakey,-value,-visibility)に合わせて、列方向に境界のない`2:2`形式の行範囲へ変更しました。モックでも境界付き範囲へのメタデータ追加を拒否するようにし、失敗を再現してから修正しています。

修正後は、保存済みデータを保持した再インポートで不足している行メタデータを補修し、追加行の重複なしで完了しました。履歴の`IMPORT / OK / 全件ID一致`とバックアップの`COMPLETE`を読み返して確認しています。GmailへのCREATE/REPLACE/DELETEは実行していません。実アカウントのメールアドレス、フィルター定義、ファイルIDはこのレポートへ掲載しません。
